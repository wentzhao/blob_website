# Git 与 Pull Request 规则

状态：AI 初稿，待 wentZh2004 确认。确认前本文只提供建议，不构成强制规范。

## 仓库信息

- 目标 remote：`https://github.com/wentzhao/blob_website.git`
- 默认 base 分支：暂按 `main`，实际创建 PR 前以远程仓库状态核对。
- PR 标题和描述：默认使用中文；用户临时指定其他语言时以用户要求为准。

## 分支与提交

- 功能修改使用独立分支，不直接在 `main` 上实现或创建 PR。
- 分支名应简短表达目的；具体格式以用户确认的约定为准。
- 提交前检查改动范围、未跟踪文件和测试结果，避免把无关改动带入提交。
- 不使用 force-push、reset 或覆盖工作区来隐藏问题。

## 推送与 PR

- 提交、推送、创建 PR 和合并是不同动作，不共享默认授权。
- 未获得明确授权时，不自动推送；创建 PR 前先展示仓库、base/head、标题、描述和验证结果预览。
- PR 描述应说明目的、主要改动、验证结果、已知限制和关联 issue；没有关联 issue 时明确写无。
