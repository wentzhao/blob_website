# 测试与验证规则

状态：AI 初稿，待 wentZh2004 确认。确认前本文只提供建议，不构成强制规范。

## 默认验证

- 修改 TypeScript、Astro、Svelte 或内容 schema 后，运行 `pnpm exec astro check`。
- 涉及页面、路由、内容、Markdown 插件或构建配置后，运行 `pnpm build`。
- 修改纯文案或单个样式时，至少检查受影响页面；涉及响应式布局、交互或主题时进行浏览器手工验证。

## 验证要求

- 记录实际执行的命令和结果，不把未执行的检查写成通过。
- 构建失败时先定位原因，不通过删除检查、跳过页面或降低校验来“修复”。
- 当前项目没有专门的自动化测试脚本；新增测试框架前应说明收益、范围和维护成本，并由用户确认。
- 内容变更至少验证目标 locale、草稿过滤、文章详情路由和构建产物是否符合预期。
